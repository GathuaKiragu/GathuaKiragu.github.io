The problem

High-frequency sensor updates created elevated MySQL workload during a 1,000-sensor BLE pilot.

My contribution

I investigated the database load, introduced Redis caching, and reduced how frequently sensor updates were persisted.

Technical challenge

The data pipeline needed to manage database writes while handling frequent readings from the pilot devices.

Outcome

The data handling approach was reworked for the pilot. Performance improvement has not yet been measured; this is pilot scale, not a production rollout claim.
